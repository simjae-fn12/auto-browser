# 가격·상품 비교

## 절대 하지 않는 것

구매, 결제, 장바구니 담기, 쿠폰 받기, 회원가입, 리뷰 작성은 하지 않는다. 사람이 채팅에서 명확히 시킨 경우에도 결제 직전 화면에서 멈추고 확인을 받는다.

## 순서

1. **상품 특정**: 모델명, 용량·색상·수량 같은 옵션을 확인한다. 정확한 모델명이 없으면 후보 2~3개를 보여 주고 고르게 한다.
2. **검색**: 자기 세션의 탭에서 아래 쇼핑몰을 검색한다. 사람이 쇼핑몰을 지정했으면 그곳만 본다.
   - 네이버쇼핑 `https://search.shopping.naver.com/search/all?query=<검색어>` (가격비교 묶음이 있으면 우선 사용)
   - 쿠팡 `https://www.coupang.com/np/search?q=<검색어>`
   - 11번가, G마켓, 공식 스토어
3. **같은 상품인지 확인**: 옵션, 수량, 정품/병행수입, 리퍼·중고 여부를 확인한다. 다른 상품은 비교표에서 빼거나 따로 표시한다.
4. **기록**: 쇼핑몰, 판매자, 상품가, 배송비, 총액, 도착 예정일, 평점(리뷰 수), 할인 조건(카드·멤버십), URL, 확인 시각
5. **저장**: 작업 폴더에 `YYYY-MM-DD 상품명 가격비교.csv`로 저장한다. 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM으로 쓴다.

## 답변 형식

- 총액(상품가 + 배송비) 기준 최저가 1~3곳을 표로 보여 준다.
- 카드 할인이나 멤버십 가격처럼 조건이 붙은 가격은 조건 없는 가격과 따로 적는다.
- 가격은 확인한 시각 기준이며 바뀔 수 있다고 한 줄로 밝힌다.
- 로그인 상태에 따라 보이는 가격(회원가, 쿠폰가)이 다를 수 있다고 알린다.
