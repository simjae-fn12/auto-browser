# 페이지 표·데이터 추출

## 순서

1. **대상 확인**: "이 페이지"라고 하면 `browser.activeTab()`을 쓴다. 표가 여러 개면 snapshot으로 표 제목과 행 수를 보여 주고 어떤 표인지 묻는다.
2. **구조 파악**: `js`로 표 구조를 읽는다. 클릭이나 입력은 하지 않는다.

   ```js
   const rows = await tab.js(`[...document.querySelectorAll('table')[0].rows]
     .map(r => [...r.cells].map(c => c.innerText.trim().replace(/\\s+/g, ' ')))`);
   ```

   `<table>`이 아닌 카드형 목록은 반복되는 항목 요소를 찾아 필드(이름, 가격, 링크 등)별로 뽑는다. 링크는 `href`의 절대 주소로 저장한다.
3. **여러 페이지**: "다음" 버튼이나 페이지 번호가 있으면 `click`으로 넘기고 `wait`로 기다린 뒤 다시 읽는다.
   - 사람이 범위를 정하지 않았으면 최대 10페이지까지만 모으고, 더 있다고 알린다.
   - 무한 스크롤은 `scroll`로 내리면서 행 수가 더 늘지 않을 때까지 모은다.
4. **정리**: 헤더 행은 한 번만 둔다. 숫자 열의 쉼표와 단위(원, %)는 별도 열로 나누거나 숫자만 남긴다. 중복 행은 뺀다.
5. **저장**: 작업 폴더에 `YYYY-MM-DD 페이지제목.csv`로 저장한다.
   - 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM(`﻿`)으로 시작한다.
   - 쉼표, 따옴표, 줄바꿈이 들어간 칸은 따옴표로 감싸고 안쪽 따옴표는 `""`로 바꾼다.

## 확인과 보고

저장한 뒤 파일 행 수와 화면에서 센 행 수가 맞는지 확인한다. 답변에는 행·열 수, 처음 3행 미리보기, 파일 경로를 쓴다.

로그인해야 보이는 개인 정보(주문 내역, 계좌 등)를 추출할 때는 파일이 문서 폴더(OneDrive 동기화 가능)에 저장된다는 점을 알린다.
