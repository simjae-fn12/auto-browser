    다운로드 폴더

    AI

    AI 패널에서 실행하는 Claude·Codex에 적용됩니다. 모델·추론·권한·작업 폴더는 대화마다 패널 아래쪽에서 고릅니다.

    대화

    작업 중에 보낸 메시지바로 반영하면 진행 중인 작업에 곧장 끼워 넣고, 대기열은 지금 작업이 끝난 뒤 차례로 보냅니다.
    현재 탭을 함께 보내기새로 연 패널에서 "현재 탭" 칩이 켜진 채로 시작합니다.
    맞춤 지시사항모든 대화의 시스템 프롬프트 앞에 붙습니다. 예: "답은 한국어로 짧게", "결제 직전에는 꼭 물어봐".

    브라우저 조작

    AI가 조작하는 탭 따라보기패널에 보이는 대화가 다른 탭을 조작하면 그 탭으로 화면을 옮깁니다.
    페이지 위에 작업 표시테두리, 상태 알약, 커서, 클릭 표시를 보여 줍니다. 끄면 페이지가 바뀌지 않습니다.
    쓰지 않는 AI 탭 정리세션의 모든 탭이 이 시간 동안 쓰이지 않으면 닫습니다. 보고 있는 탭은 닫지 않습니다.

    알림

    작업이 끝나면 알리기다른 창을 보고 있으면 작업 표시줄의 Oinzi 단추가 깜빡입니다.
    알림음Windows 시스템 소리를 씁니다. 실패하면 다른 소리가 납니다.

    계정

    계정마다 설정 폴더를 따로 둡니다(Claude는 CLAUDE_CONFIG_DIR, Codex는 CODEX_HOME). 그래서 로그인 정보 파일을 바꿔 끼우지 않아도 되고, 토큰이 갱신돼도 각 계정 폴더 안에서 갱신됩니다. 바꾼 계정은 다음에 시작하는 작업부터 적용되며, 이미 실행 중인 작업은 원래 계정으로 끝까지 진행합니다. 설정·스킬·MCP 서버는 기본 계정의 것을 같이 씁니다.

    프로필·사이트 계정

    프로필은 Chrome 프로필처럼 로그인 상태(쿠키)를 따로 둡니다. 같은 사이트에 여러 계정으로 동시에 로그인해 둘 수 있습니다. 프로필마다 사이트 계정을 저장해 두면, AI가 작업에 맞는 프로필과 계정을 골라 로그인합니다. 비밀번호는 Windows 계정으로 암호화해 이 PC에만 저장합니다. AI는 비밀번호를 볼 수 없고, Oinzi는 저장된 사이트의 로그인 화면에만 비밀번호를 입력합니다. 단, 전체 권한처럼 이 PC에서 명령을 마음대로 실행할 수 있는 AI는 같은 Windows 계정의 저장 파일을 직접 풀 수 있으니, 중요한 계정은 그런 대화에서 쓰지 마세요.

    확장 프로그램

    Chrome 웹 스토어의 확장 프로그램을 프로필마다 따로 설치합니다. 설치한 확장의 버튼은 사이드바 주소창 아래에 나오고, 누르면 확장 화면이 열립니다. 웹 스토어 페이지를 열면 사이드바에 「Oinzi에 추가」 버튼도 나옵니다. 일부 확장은 Chrome 전용 기능을 써서 제대로 동작하지 않을 수 있습니다.

    프로필

    예약 작업

    정해 둔 요청을 매일·매주·몇 시간마다 AI에게 맡깁니다. 실행마다 "[예약]" 대화가 새로 생기고, 끝나면 Windows 알림이 옵니다. Oinzi가 켜져 있을 때만 실행되며, 꺼져 있던 동안 놓친 예약은 다음에 켤 때 한 번 실행합니다. 예약 실행에서는 결제·게시·전송처럼 되돌릴 수 없는 일을 하지 말라고 AI에게 알려 줍니다.

    Windows 시작 시 Oinzi 실행예약 작업이 놓치지 않고 돌도록 로그인할 때 Oinzi를 켭니다.

    녹화

    개인 정보

    자동 완성과 비밀번호 저장웹 페이지 입력란에 저장된 값을 제안하고, 로그인할 때 비밀번호 저장을 묻습니다.
    인터넷 사용 기록 삭제모든 탭이 같은 프로필을 쓰므로 AI 탭의 기록도 함께 지워집니다. 쿠키를 지우면 사이트에서 로그아웃됩니다.

    에이전트 연결

    터미널의 Claude Code나 Codex가 Oinzi를 브라우저로 쓰게 하려면 MCP 서버를 등록합니다. Oinzi는 다른 프로그램의 설정 파일을 직접 고치지 않으므로, 명령을 복사해 직접 실행해 주세요.

    MCP 서버
    등록 명령 복사한 번만 등록하면 됩니다. Oinzi를 켤 때마다 같은 경로에 최신 서버를 써 둡니다.
